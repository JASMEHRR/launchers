# Launchers

One-click Windows launchers for my projects: Ascend, ATLAS, ClipForge, Jarvis, LaunchKit, Habit Arena, Content OS and more.

- Each `.bat` file starts one project.
- `LAUNCH ALL.bat` starts everything at once.
- `CREATE SHORTCUTS.bat` (or `make-shortcuts.ps1`) puts desktop shortcuts with the icons from `icons/`.
